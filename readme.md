# Caliburner
Isometric 2d turn based strategy game
medieval science-fantasy setting
- 2.5d isometric fake 3d terrain rollercoaster tycoon style but using pre drawn sprite blocks
- ONLY DWARFS NO HUMANS
- Weapons
    - Flying ROCKET SWORDS
    - Steam lance shoots forwards with a burst of steam
    - Truck
    - Shock stick (electrified quarter staff)
    - Cluster sword (cluster missile that splits into a bunch of swords)
    - MACHINE BOW
    - TUNGSTUN BOLT CROSBOW
    - Forge hammer (An eternally flaming hammer only avaialble for dwarfs with the priest job)
- armour
    - Nuclear powered knight armour
- cybernetically enhanced horses that go 200 km/h
- Modes
  - kerfuffle (1v1) (skirmish mode is a barbrawl)
  - Embark on Legend (objective based campaign mode)
- Chariot harvesters (resource collection mechanic?)
- Space piracy
- Space mercs
- All dwarfs have economic jobs.
- Any dwarf may have a weapon / armour
- Alcohol buff
- Dwarfen't, failures of dwarfs that refuse into caves and mountains
- High Saint Hatsune miku (she's on weed)
- Lootbox merchants (Economic Arrogance Inc)
- Dwarfs can join differing religions
- Cult of Teto
- Dwarfen Church (Priests are blacksmiths)
    - Pope = High pontiff Rust beard.
- Religious clash causes trouble?
- Blatant theft (in game mechanic)
- Resources
    - Radio active potatos
    - ironic carrots
    - Copper apples
    - Glass flax
    - Lead beans (They have a cult around them [LEADED BEANS])
    - Gun flower (flowers that produce gun powder)
    - Tea Leafs (tin leafs)
      in C++
